Hands-on cloud infrastructure exercises from the [Boot.dev Learn AWS](https://www.boot.dev/courses/learn-aws) course.

The course focuses on building, configuring, securing, and managing cloud infrastructure using the AWS Management Console and AWS CLI.

## Topics Covered

| Category | Services & Concepts |
| --- | --- |
| Cloud Fundamentals | Regions, Availability Zones |
| Networking | VPC, Subnets, Route Tables, Internet Gateways, NAT |
| Compute | EC2, Elastic IPs, SSH, Launch Templates |
| Databases | RDS, PostgreSQL, DB Subnet Groups |
| Security | IAM, Roles, Policies, Security Groups |
| Monitoring | CloudWatch |
| DNS | Route 53 |
| Object Storage | S3 |
| Content Delivery | CloudFront |
| Containers | ECS, Docker |
| Serverless | Lambda |

## Repository Contents

- `app.py` — Python HTTP server integrated with AWS Systems Manager Parameter Store using Boto3.
- `Dockerfile` — Container configuration for the Python application.

## Tools & Technologies

AWS Management Console, AWS CLI, Linux, Bash, Docker, Python, Boto3.

## Notes

Most infrastructure exercises were performed directly within AWS rather than through source code.

This repository contains the application code used during the containerization exercises.
